# Rhea.js 1.0.2

Dependency security release. `npm audit` now reports 0 vulnerabilities for this repository and for every generated project, development dependencies included.

- **Security:** generated projects no longer depend on `nodemon` (it pulled a vulnerable `braces` with no fix). `npm run dev` uses `tsx watch` (TypeScript) or `node --watch` (JavaScript).
- **Security:** Vitest and `@vitest/coverage-v8` moved to `~5.0.5` (fixes GHSA-82fw-gwwq-j7x9 and GHSA-qxg6-89mg-rqv8). ESLint moved to 10.13.
- **npm 12:** TypeScript projects declare `allowScripts` for `esbuild`, so installs work without a blocked-script warning.
- **Changed:** generated projects and repository tooling need **Node.js 22.13 or newer** (was 20.19). `@rheajs/core`, `@rheajs/auth` and `@rheajs/cli` still declare `node >=20`; only 22 and 24 are tested.
- **Added:** `npm run test:security` and `npm run audit:all`, a CI audit job, generated-project audit job and a daily audit.

Existing projects: in `package.json` set `vitest` and `@vitest/coverage-v8` to `~5.0.5`, `eslint` and `@eslint/js` to `^10`, remove `nodemon` and `nodemon.json`, set the `dev` script as above, and run `npm install`. TypeScript projects: add `"allowScripts": { "esbuild": true }`.
